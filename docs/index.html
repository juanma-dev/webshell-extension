What you can do

⚡ Extract anything to CSV

Tables, product lists, links, images. extract table | to-csv > data.csv and it's on your disk.

🎯 Point & click selectors

Type pick, click the thing you want — WebShell writes a stable CSS selector for you and skips machine-generated class names.

🔔 Watch for changes

watch .price 30 sends a desktop notification when a price drops or stock returns. Watches survive page reloads.

🧭 Navigate like a filesystem

cd .., cd -, pwd — treat the site as a directory tree, and the terminal reopens after every jump.

🌐 curl & ping, in the page

Query any API and pipe the result: curl api.github.com/zen | download zen.txt. Check latency without leaving the tab.

🔒 Private by design

Plain JavaScript, runs 100% locally, zero analytics. The source is public — audit every line.
